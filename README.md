# ⛏️ Minecraft WASM

A voxel / Minecraft-like 3D game built from scratch in **Rust** and compiled to **WebAssembly (WASM)**.

## 🎯 Learning Goals
- Rust fundamentals: Ownership, Borrowing, Structs, Enums, Math/Vectors.
- WebAssembly internals: Linear memory, exports, JS-Wasm boundary, zero-copy buffers.
- Voxel 3D Engine: Voxel grid representations, DDA raycasting / meshing, block break & place, first-person physics, and lighting.
